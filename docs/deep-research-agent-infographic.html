2 — Dual-pass research system
The recommended workflow. Two passes with different source quality modes, merged by an LLM synthesis step.
dual_pass.py
Entry point — orchestrates both passes
↓
Pass A — Practitioner stories
ENABLE_SOURCE_QUALITY=false
  • Broad, unfiltered web search
  • No source classification
  • No dashboard or scoring
  • Rich in named examples, numbers
→ output/*_PassA.md
Pass B — Structured framework
ENABLE_SOURCE_QUALITY=true
  • Quality-guided search
  • Tier classification per result
  • Cumulative scoring across rounds
  • Structured framework output
→ output/*_PassB.md
↓
LLM Synthesis
Merges Pass A stories into Pass B's structure → output/*_Report.md
Both runs share the same API key and rate limits. Recovery: if a pass fails, partial output is preserved and no synthesis is attempted — the user can manually merge.

4 — Tool internals
Two primary tools and what they produce.
Search Serper.dev
Google search via HTTPS API
Input
{query: ["cold email rates 2026", "outreach conversion data"],
 cumulative_scores: {tier1_count: 3, tier2_count: 5, total_possible: 84}}
What it does
1
POST to google.serper.dev/search
With API key, query, location (US/China based on content language), 5 retries with exponential backoff
2
Parse organic results → web_snippets
Extracts title, URL, date published, source, snippet. Filters out video placeholders.
3
Append Source Quality Dashboard
Scores each result by tier, updates cumulative running count, appends to response. Skipped when ENABLE_SOURCE_QUALITY=false.

Visit Jina.ai + LLM
Page reader with AI extraction
Input
{url: ["https://example.com/article"],
 goal: "Extract specific job-finding methodology"}
What it does
1
GET r.jina.ai/{url}
Jina.ai Reader API → page as markdown. Up to 3 retries with 50s timeout. Falls back to alternative parser.
2
Truncate to 95K tokens
Uses tiktoken cl100k_base encoding. Long pages are truncated — not split, just the first N tokens.
3
LLM extract: EXTRACTOR_PROMPT
Secondary LLM call with the extraction prompt. Returns JSON: {rational, evidence, summary}. Extractor retries up to 3 times if output is too short, truncating content 70% each retry.
Output

Summary:

5 — Source Quality Dashboard
Every search result is scored by credibility tier. Running cumulative score tracks coverage across rounds.

The main custom code is source_quality.py — a 417-line classification engine that runs on every search result. Each result's domain, URL path, and snippet are checked against known academic publishers, government TLDs, institutional domains, affiliate patterns, anecdotal keywords, and platform hosts. A tier label, score, per-batch dashboard, and cumulative running total are appended to every search tool response.

The cumulative score is carried across rounds via a structured state-passing pattern — the model passes the JSON blob from the last dashboard as cumulative_scores in its next search call's arguments. The code merges the new batch and hands back the updated tally. If the model forgets, it starts fresh — no functional breakage.

The entire system can be toggled off with ENABLE_SOURCE_QUALITY=false — the agent runs exactly like the base Alibaba code, no classification, no dashboard. This toggle is how the dual-pass runner switches between its two research modes.

>70% → strong coverage, may proceed to answer

6 — Token anatomy per round
What fills up the context window each iteration. The context window grows with every round.

Each round adds:

System prompt (pinned)~800 tokens
User query~30 tokens
Model tool call~40-80 tokens
Search response (10 results)~800-1500 tokens
Visit response (1 page)~400-600 tokens
Report generation~1500-3000 tokens

Typical session (8 rounds)

Total input tokens~15K-25K
Total output tokens~2K-4K
DeepSeek V4 cost~$0.30
OpenAI GPT-4o cost~$0.50-$1.00
Serper.dev API calls3-4 searches
Jina.ai page reads5-8 visits
Context window growth:
The context window grows by 1-2K tokens per round. At round 8, you're at ~16K total input. 320K max means this can theoretically go 150+ rounds before the model loses history — but in practice the model converges well before that.
